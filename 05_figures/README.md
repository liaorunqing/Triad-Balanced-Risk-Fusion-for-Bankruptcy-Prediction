# Figure Files

`manuscript/` contains the seven figures used in the revised submission.
Figure 1 is supplied in PDF and PNG form; Figures 2–7 are supplied as 300-dpi
PNG files.

`additional_diagnostics/` contains supporting feature-selection and
operating-point figures that are useful for audit but are not part of the main
seven-figure sequence.

All main figures can be regenerated with the scripts in
`02_code/04_manuscript_analysis/`.
