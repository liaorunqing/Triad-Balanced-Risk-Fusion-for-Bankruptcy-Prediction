# Data Availability

The Polish Companies Bankruptcy data are publicly available from the UCI
Machine Learning Repository at <https://doi.org/10.24432/C5F600> and are
included in this repository under the Creative Commons Attribution 4.0
license.

The cross-regional analysis uses Supporting Information files associated with
Alaminos, del Castillo, and Fernández (2016), available from
<https://doi.org/10.1371/journal.pone.0166693>. Because the source documentation
states that the underlying firm-level data were provided under license from
Standard & Poor's COMPUSTAT, those workbooks and the reconstructed
financial-ratio table are not redistributed here. Download instructions,
data-preparation scripts, per-seed outputs, statistical summaries, figure
files, and source code are provided in this repository.
