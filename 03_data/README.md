# Data Sources

## Redistributed dataset

`01_raw/polish_bankruptcy/` contains the five ARFF files from:

> Tomczak, S. (2016). *Polish Companies Bankruptcy* [Dataset]. UCI Machine
> Learning Repository. <https://doi.org/10.24432/C5F600>.

The UCI record licenses this dataset under CC BY 4.0. Retain attribution when
copying or adapting it.

## Non-redistributed regional source files

`01_raw/pone_global_2016/` and `02_processed/pone_global_2016/` contain only
`.gitkeep` placeholders in the public release. Follow
`PONE_DATA_INSTRUCTIONS.md` to obtain the publisher-hosted workbooks and build
the local analysis table. Do not commit those files or the reconstructed
firm-level CSV.
